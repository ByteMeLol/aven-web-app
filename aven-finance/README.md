# Aven Finance — React + Vite + TypeScript + PWA

A responsive, Aven-inspired finance app starter. The frontend uses the Spring Boot API for authentication, accounts, transactions, and internal Aven Wallet transfers. ClickPesa is intentionally not connected yet; deposits currently use the internal wallet endpoint so the provider adapter can be added when API credentials and webhook details are available.

## Included
- Responsive desktop sidebar and mobile bottom navigation
- Home dashboard, wallet cards, activity list, spending summary
- Separate sign-in and registration screens (prototype UI only)
- Dedicated Profile screen with editable name/email, image upload preview, and sign-out
- Add-account flow for cash, mobile money, bank, savings, and shared wallets
- Default Aven Wallet card with planned Deposit and Withdraw actions
- Add income/expense modal, category and wallet selectors
- Display-currency switcher (USD, TZS, EUR, GBP, KES)
- Balance visibility toggle, search, receive/send placeholder screens
- Installable PWA configuration with offline app-shell caching
- Express + Prisma + PostgreSQL schema prototype retained for reference

## Requirements
- Node.js 20 LTS or newer
- npm
- PostgreSQL 15+ (only needed for the API/backend stage)

## Run the frontend
From this folder:

```bash
npm install
npm run dev
```

Open the local URL Vite prints, usually `http://localhost:5173`.

Build and test the production bundle:

```bash
npm run build
npm run preview
```

For PWA installation, use a production build or HTTPS deployment. The service worker is generated by `vite-plugin-pwa`. Browser install UI varies by browser and device.

## Currency note
Changing the display currency currently formats the same sample amounts in the selected currency. It **does not convert balances**. Real conversion needs a trusted FX rate source, timestamps, rounding rules, and clear handling of stale rates. Each account and transaction should store its own currency.

## Backend setup
```bash
cd server
cp .env.example .env
# Edit DATABASE_URL and set a long random JWT_SECRET
npm install
npx prisma generate
npx prisma migrate dev --name init
npm run dev
```

The active finance API is the Spring Boot application in `../aven`. Each user has one Aven Wallet whose currency is USD or TZS and follows the selected display-wallet currency (currency changes are allowed only while the wallet balance is zero). The API exposes authenticated account, transaction, deposit, withdrawal, and transfer endpoints. Deposit and withdrawal requests currently stop at the ClickPesa provider boundary with a clear not-configured response; no balance is credited or debited until ClickPesa confirms the operation. The Express/Prisma server remains an unused prototype until a deliberate consolidation decision is made.

## Important production work before real money
- Use a regulated payment provider and complete its onboarding/compliance requirements for your market.
- Never treat a client-side balance as authoritative. Use a server-owned double-entry ledger and atomic transactions.
- Add verified email OTP, rate limits, abuse protection, password reset, session revocation, audit logs and secure secret management.
- Implement idempotency for money movement and reconcile provider webhooks.
- Do not use the sample receive QR or payment ID for real transfers. Deposit and Withdraw buttons are informational placeholders and do not move money.
- Add tests, monitoring, backups, privacy policy, terms, and security review before production.
